# Authority

Windows üzerinde Codex ve PowerShell oturumlarının yönetici token durumunu ve gerçek işlem erişimini kontrol etmeye yönelik kişisel Codex skill paketi.

## İçerik

Skill paketi `skills/authority/` altındadır. Ana yönerge `skills/authority/SKILL.md` dosyasıdır.

## Yerel kullanım

`skills/authority` klasörünü Codex kullanıcı skill dizinine (`~/.codex/skills/authority`) kopyalayın. Skill içindeki araç ve platform gereksinimlerini kullanmadan önce inceleyin.

Bu depo mevcut yerel skill dosyalarının kaynak kopyasını içerir. Python önbellekleri pakete dahil edilmez.
